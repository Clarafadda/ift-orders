# IFT Orders (Vue 3 + Firebase)
1. `npm install`, copy `.env.example` to `.env` and fill in the Firebase values.
2. Firebase console: enable Authentication > Google, create Firestore, deploy `firestore.rules`.
3. Replace `public/ift-logo.svg` with the official logo and the fonts in `src/styles/tokens.css`.
4. `npm run dev`
